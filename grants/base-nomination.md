# Base Builder Grant nomination package — ProofRail

## Project
ProofRail — verifiable work and payment receipts for autonomous agents.

## Shipped today
- public MIT OR Apache-2.0 repository
- deterministic receipt core and tamper detection
- CLI verification
- x402 exact-payment challenge validator
- Base-compatible network validation (`eip155:8453`)
- public GitHub Pages demo/spec

## Why Base
ProofRail is infrastructure for agentic commerce: it binds work evidence to payment evidence without turning the receipt protocol into a wallet or custodian. Base already has strong x402/USDC and agent infrastructure, making it the natural first live payment adapter.
