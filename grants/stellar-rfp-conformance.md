## SDK release check (2026-10-07)

- **Current published npm `latest`: `@x402/stellar` 2.27.0**, verified against [npm version history](https://www.npmjs.com/package/%40x402/stellar?activeTab=versions). Its documented public surface is still client/server/facilitator **`exact`** support with auth-entry signing; **`upto` is a requested upstream deliverable, not an existing Stellar feature claim**.
- **Previously recorded local spike: 2.26.0** pinned/import-tested. That result is **version-specific**. This document update did **not** install, import-test, compare package exports, or run canonical E2E against 2.27.0. Do **not** silently relabel 2.26.0 evidence as 2.27.0 proof.
- **Upgrade/revalidation gate:** in a runnable Node environment, pin 2.27.0 with compatible official `@x402/core` / MCP dependencies, capture package lock and licenses, import client/server/facilitator exports, verify testnet/pubnet CAIP-2 and token constants, compare `/supported` + `payload: {transaction}` wire contract, run no-spend negatives, then official testnet and authorized mainnet canonical e2e with real settlement receipts. Record commands, versions, date, results and hashes before changing a readiness claim to "verified on 2.27.0". Live mainnet tests need explicit budget/wallet approvals.
- **Acceptance status today:** matrix is a requirements-to-evidence plan, **not** successful Stellar deployment, upstream `upto` merge, invitation, Build submission, or SCF funding.
